Always-on (wraps every step)

L7 Reconciliation — runs after every step; mandatory; cannot be switched off. Scale: partition counts + aggregates + sampling.
L9 Control & Logging — config · watermark · DAG · approvals · and append-only logs: run / step / table / file / schema / type-mapping / DQ / reject / recon / error. Crash-safe.
Security — data never leaves client · no telemetry · secrets by reference · roles · config + state at client. Code shipped only as obfuscated wheel.
